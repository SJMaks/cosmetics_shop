# Cosmetics Shop

Небольшое Flutter-приложение с интерфейсом магазина косметики. Проект выполнен в рамках тестового задания на позицию Flutter-разработчика-стажёра.

## Возможности

- Главный экран с каруселью рекламных баннеров и акций.
- Список категорий косметики.
- Подборки товаров: новинки, акции и хиты продаж.
- Отдельные переиспользуемые виджеты для элементов интерфейса.
- Подготовленные светлая и тёмная темы оформления.

## Технологии

- Flutter
- Dart
- Material 3

## Запуск проекта

Установите [Flutter SDK](https://docs.flutter.dev/get-started/install), затем выполните в корне проекта:

```bash
flutter pub get
flutter run
```

Проект представляет собой небольшой UI-прототип витрины магазина; полноценный backend и оформление заказов не реализованы.
